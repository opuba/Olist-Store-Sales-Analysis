Olist E-Commerce Sales & Business Performance Analysis

Project Overview

This project explores the Brazilian E-Commerce Public Dataset by Olist to analyse sales performance, customer behaviour, product performance, payment preferences, and delivery operations.

The objective is to transform raw transactional data into meaningful business insights that can help an e-commerce business understand its revenue drivers, identify operational challenges, and improve customer satisfaction.

The analysis uses Power BI to develop an interactive dashboard that presents key business performance indicators and allows users to explore different aspects of the business.

Business Objectives

The project seeks to answer the following business questions:

How is the business performing in terms of revenue and order volume?

Which product categories generate the highest revenue?

Which customer cities contribute the most orders?

Tools & Technologies

Power BI Desktop – Data modelling, DAX calculations, and interactive dashboards.

Power Query – Data cleaning, transformation, and preparation.

DAX – Measures, calculated columns, and business performance metrics.

GitHub – Project documentation and version control.

Dataset Description

The project uses the Brazilian E-Commerce Public Dataset by Olist, available on Kaggle.

The dataset contains approximately 100,000 orders placed between 2016 and 2018 across multiple marketplaces in Brazil.
